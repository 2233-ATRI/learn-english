# 拾词 · 考研英语二

适合安卓平板的离线阅读训练应用。把一篇阅读串成「先看大意与方法 → 点词精读 → 作答 → 对照解析 → 复习生词与错题」。

## 安装与打开

- [下载安卓安装包 v1.1.0](https://github.com/2233-ATRI/learn-english/raw/refs/heads/main/releases/拾词英语二-1.1.0-Android.apk)。传到平板后，用系统文件管理器打开并安装。要求 Android 8.0 或更新、Android System WebView 120 或更新。
- [下载安装与使用资料包](https://github.com/2233-ATRI/learn-english/raw/refs/heads/main/releases/拾词英语二-安装与使用.zip)，包含 APK、离线网页版和安装说明。

## 内容

- 2010—2026 年英语二阅读 A，共 68 篇、340 道选择题，来自用户提供的真题资料，来源文件名保留在题库中。
- 6 篇原创短篇练习，共 30 道选择题，附段落译文、逐项选项说明。
- 每篇有中文大意、段落结构与 3 条阅读技巧。全部 370 题新增独立编写的定位词、定位步骤、原文短证据及中文、关键词推理和四项取舍理由，共 1480 条选项说明。真题参考答案来自随卷机构资料，技巧解析为新编学习辅助；来源文件名随篇目保留。
- 词库以 [ECDICT](https://github.com/skywind3000/ECDICT) 的 ky 标记筛出 4801 个考研词，补齐 925 个常见基础词，共 5726 个基础词条、10379 条词形映射，另有教学词、常用缩写补充。考研标签来自该开源数据集。按内置真题正文出现次数计算，可查询比例约 93.7%；专名和核心词库之外的词可自行补充释义。

2025 年 Text 2 第 30 题的机构参考答案为 D，但原文末段也为 C 提供直接推断依据。应用已标记“答案待复核”，保留作答与说明，该题暂不计分，也不纳入错题本。其余 369 道内置题参与评分。

已逐题核对交付 APK 中的全部答案，核对范围与逐年结果见 [答案核对记录](releases/答案核对结果-2026-11-14.txt)。

当前训练模块是阅读 A。原卷中的完形填空、新题型、翻译和写作尚未编成训练模块。真题保留英文原文；逐段中文译文目前配在原创练习中。

## 阅读操作

1. 在书架筛选年份或原创练习，打开一篇文章。
2. 阅读大意与技巧，点击「开始阅读与答题」。
3. 轻点英文单词查看中文、原形及可用音标；再点同一个词收起，点另一个词切换释义。点空白、关闭按钮或滚动也会收起。
4. 作答前可点「看定位提示」，了解要圈什么词、看哪一段；点击定位词会跳到原文并高亮。展开提示会记录为使用过阅读辅助。
5. 点击选项字母作答，选项中的英文仍可单独查词。提交后按「怎么找定位词 → 先读这几句 → 用少量关键词判断 → 四个选项怎么取舍」查看完整解析。证据句有中文说明，点「在原文中看这句」可高亮原句，再点「返回这道题」继续核对。
6. 「收藏生词」保存单词、释义、原句与篇目。生词复习按认识程度安排间隔；「还不熟」安排次日再看。
7. 错题本按每篇最近一次已提交练习更新，也能展开完整定位与排除步骤。「再练一次」保留上一轮记录，新一轮交卷后更新错题。

书架的「低词汇量做题法」、导读的「做题方法速查」和阅读提示内都能查看通用方法：特殊词定位、利用题序、关系词路标、例证题找观点、主语/范围/语气核对、主旨态度题和跳题策略。每题具体解析优先指向少量原文证据；主旨与复杂推断会合看几处证据。

平板横屏宽度足够时，原文与题目并排并各自滚动。竖屏、分屏或窄窗口通过「阅读原文 / 题目与解析」切换。阅读字号可调，支持暖纸、清透、夜读三种外观。计时只累计阅读页在前台且未手动暂停的时间。

## 导入与导出

「导入资料」支持：

- PDF、TXT、Markdown：提取或粘贴一篇正文，检查段落，再填写中文大意与技巧，作为点词精读材料。扫描 PDF 需要先 OCR；本应用的 PDF 导入提取现有文字层。单文件上限 20 MB、PDF 上限 100 页。
- 完整题库 JSON：同时导入文章、题目、答案、解析、导读和篇内词义。应用中可以导出原创示例作为格式模板；答案使用 0=A、1=B、2=C、3=D，暂无答案填 null。id 应唯一，重复 id 会提示修改，避免覆盖已有练习。

自行导入的文章由导入者填写导读，或使用已含导读的题库 JSON。内置文章已提前编写好导读。

完整题库 JSON 的每题可选填 strategy：type、anchors（text / meaning）、locate、evidence（paragraph / quote / meaning）、reasoning、options（四项理由）。paragraph 从 0 开始；定位词须在正文出现，引文须逐字匹配所指段落。导出的格式示例包含完整技巧字段。旧格式仍支持，用户导入题目需要自行补充技巧解析。修改正文时会清除旧的句子定位与技巧，避免引用错位。

「阅读设置 → 导出完整备份」包含全部学习记录、生词、自定义释义和导入篇目。备份可用于手机、平板与网页版之间手动迁移。「恢复备份」会替换目标设备当前数据，恢复前会显示数量并确认。

## 数据与离线运行

安卓应用不申请联网权限和广泛存储权限，使用系统文件选择器访问选中的文件。界面直接读取内置资源，通过 WebView 的本地拦截提供页面；不启动 HTTP 服务。数据在应用私有目录的 workspace.json 中以原子写入保存。

网页版使用 IndexedDB，数据与安卓应用相互独立。清理浏览器数据、卸载应用或更换文件位置可能影响本地记录。更换设备或卸载前请导出备份。保存失败会在界面提示。

## 从源码构建

使用支持 `import.meta.dirname` 的 Node.js（例如 Node.js 22 或更新版本），依赖版本见 package.json。从仓库下载后，在项目目录执行：

```bash
npm install
npm run build
npm test
```

离线网页生成在 `dist/index.html` 和 `releases/拾词英语二-离线版.html`。构建安卓安装包时执行：

```bash
npm run build:android
```

安卓构建需要 Node.js、Java 21、Android SDK Platform 35、Build Tools 35.0.0，无需 Gradle。默认使用 ~/Library/Android/sdk，可通过 ANDROID_SDK_ROOT 和 JAVA_HOME 指定位置。构建不连接设备或服务。

签名密钥保存在 .signing/，由 .gitignore 排除。首次自行构建时会生成自己的签名密钥；后续覆盖升级需要保留并使用同一密钥。仓库中的预编译 APK 使用项目原有签名，自行生成的新密钥无法用于覆盖安装该 APK。

词典筛选脚本是 scripts/prepare-dictionary.py，使用本地已下载 CSV，输出 src/core-dictionary.json。应用构建直接使用筛选后的 JSON，无需再次下载。词典来源、筛选数量及文件校验值保存在 assets/ecdict/selection.json，第三方许可证在 releases/THIRD_PARTY_NOTICES.txt。

真题内容提取脚本、逐年校验记录位于 scripts/ 和 assets/paper-text/。这些提取脚本保留了原资料目录，重新提取时需按自己的文件位置调整。日常构建直接使用 src/ 中整理后的题库。2019—2026 年数据最终经 scripts/finalize-corpus.py 校正并合并 2025 年人工转录；修正记录位于 assets/paper-text/final-corrections.json。软件检查范围见 [验证记录](验证记录.md)。

逐题技巧数据位于 src/strategies-*.json，src/lessons.js 按篇目 id 与题号接入；原创题的技巧编写脚本是 scripts/author-practice-strategies.mjs。scripts/test-strategies.mjs 检查 370 题全覆盖、引文和定位词、四项理由、导入及旧备份兼容，结果保存在 build/strategy-audit.json。
