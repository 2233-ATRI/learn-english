# 拾词英语二 1.2.0 · 安卓手机与平板

[下载安卓 APK](拾词英语二-1.2.0-Android.apk) · [项目说明与源码](https://github.com/2233-ATRI/learn-english)

把 APK 传到安卓手机或平板，在系统文件管理器中打开安装。需要 Android 8.0 或更新，以及 Android System WebView 120 或更新。

手机底部可切换原文和题目；答题时用上一题、下一题和答题卡跳转。点击单词在下方展开释义，再点同词收起。右上角阅读工具可调整字号和查看做题提示。

新版沿用原签名与数据格式，可覆盖安装 1.0.0 / 1.1.0。学习记录保存在设备本地，可在阅读设置中导出备份。
